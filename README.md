# David Li — Academic Portfolio

A concise, single-page portfolio optimized for college admissions readers who have just a few minutes to review research and accomplishments.

**Live URL:** https://dliport.github.io/

## Editing

- `src/content.js`: change name, contact details, highlights, research descriptions, awards, and activities.
- `src/components/`: reusable header, introduction, research, recognition, and footer sections.
- `styles/main.css`: design, typography, layouts, and responsive breakpoints.
- `index.html`: metadata and entry point.
- `assets/David_Li_Resume.pdf`: résumé download. Replace with an updated approved copy as needed.

No build tools, dependencies, or API keys. GitHub Pages serves this directly from `main` / `root`.

## Local preview

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## Editorial principles

The top screen communicates name, research interests, and significant results immediately. All three research projects are described directly on the page. Accomplishments are sourced from the updated September 2026 résumé. Typography uses the reader's familiar system fonts (17–19px body text), and unnecessary effects, simulated research charts, and generic quotes were removed. Layouts are responsive and support reduced-motion preferences.

Before sharing publicly, confirm all accomplishments and the preferred contact email. No home address or phone number appear on the page.
